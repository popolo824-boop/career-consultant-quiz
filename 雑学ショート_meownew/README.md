YouTube チャンネル「meownew studio」向けの、雑学ショート動画一式。
新しいセッションに引き継ぐときは、このファイルを最初に読ませる。

## フォルダの中身
| 場所 | 中身 |
|---|---|
| `YouTube投稿キット_meownew_studio.md` | 予約スケジュール、各動画のタイトル・説明文(写真クレジット入り)、予約のしかた |

| `作り方/` | 動画を作るスクリプト、素材写真、フォント |

## 動画の決まり(ここまでで決まったこと)
- **画面**: 黒背景。上に固定の2行タイトル(1行目は黄、2行目は赤、黒い縁取り)。まん中に実写の写真。写真の下のほうに、ナレーションに合わせて切り替わる黄色の字幕。
- **デッドゾーン**: 下 480px には文字を置かない。字幕とクレジットは中央から左右 350px 以内(右下のボタンを避ける)。タイトルは上端 y=190px(ご指定で上に寄せた)。
- **ナレーション**: 音声合成 Kokoro(Apache 2.0、商用可)の女性の声 jf_alpha、速さ 1.3倍。
  - 前に使った Microsoft Edge の読み上げ音声は、途中から接続できなくなった。
- **長さ**: 30〜50秒くらい。
- **写真**: パブリックドメイン、CC0、CC BY(継承条件 SA のないもの)だけを使う。CC BY のものは動画内と説明文にクレジットを書く。
- **事実**: ネットで出典を確認したものだけを使う。確認できない数字は「〜とも言われる」と弱めるか、使わない。推測は書かない。
- **文字**: M PLUS 1p Black(SIL Open Font License、商用可)。
- **ネタ元**: https://hq-improve.com/zatsugaku/ (このページの雑学から、意外さ・裏付け・自由に使える写真がそろうものを選ぶ)

## 動画の作り方(`作り方/` フォルダ)
- 必要なもの: Python 3.11、ffmpeg、`pip install kokoro soundfile pyopenjtalk-plus fugashi unidic-lite`
- `作り方/` フォルダの中で実行する(写真のパスが `zatsu/...`・`next/...` の相対パスになっている)。
- `build_telop.py`: 動画を作る本体。各動画の設定(タイトル、場面ごとの写真・ナレーション・字幕の区切り・クレジット)が `V` に書いてある。
  - ナレーションの `/` は字幕の切り替わり、`|` は字幕の改行。
  - `READ` に、読み間違いを直す表がある(例: 「X染色体」→「エックス染色体」、「小作人」→「こさくにん」)。字幕の表記はそのまま、音声だけ直る。
  - 実行例: `python3 build_telop.py gorilla gogh`(できた動画は `〇〇_telop.mp4`)
- `tts_kokoro.py`: ナレーションを字幕の区切りごとに作り、字幕の切り替え時刻を出す。
- `mkmd.py`: 台本とクレジットの md を作る。
- `next/cs.py`・`next/dl.py`: Wikimedia Commons で写真を探して、ライセンス情報ごと保存する。
  - 元の大きさの画像は取得制限(429)にかかるので、標準サイズのサムネイル(960・1280・1920px)で取る。
- 作ったら、確認用に数コマを書き出して目で見る。音声は音声認識で読みを確かめる。

## 未確認・注意
- AI の声を使っているので、YouTube の「改変または合成されたコンテンツ」の申告が必要かどうかは確認していない。
- スマホアプリで BGM を付けたまま予約できるかは試していない。
- 7・12・17・21時という時刻が伸びやすいかどうかの根拠はない(ご指定の時刻)。
- アプリの中の動画プレビューでは、ナレーションが聞こえないことがあった。動画ファイルには音が入っている(音量と音声認識で確認済み)。
