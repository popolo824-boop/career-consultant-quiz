# チャンネル設計書

作成日: 2026-08-28
前提: `01_youtube-algorithm-analysis.md` の分析結果に基づく設計。

---

## 1. ジャンル選定

アルゴリズム分析から導いた選定基準:

| 基準 | 理由 |
|---|---|
| 検索需要が明確に存在する | 新規チャンネルの初期流入は検索とShortsが主戦場 |
| シリーズ化が自然にできる | セッション貢献(2026年最重要シグナル)を稼げる |
| 視聴者の悩みが深く、満足度が取りやすい | 満足度アンケート重視時代に有利 |
| ニッチが明確で視聴履歴クラスタに載りやすい | ブラウズフィード刷新への対応 |
| 既存アセットを活かせる | 制作コストと専門性の担保 |

**選定ジャンル: 資格試験対策(キャリアコンサルタント試験)**

- 受験者は毎回2万人規模で年3回試験があり、検索需要が定期的に再生産される。
- 「過去問解説」「論述対策」「面接ロープレ」など、シリーズ化が構造的に可能。
- 合格という明確なゴールがあり、役に立てば満足度・再訪問・登録に直結する。
- 競合はまだテレビ的な作り込みが少なく、個人チャンネルでも戦える規模。
- 本リポジトリの一問一答クイズアプリ(index.html)を動画素材・誘導先として転用可能。

## 2. チャンネルコンセプト

- **チャンネル名案**: 「キャリコン試験ラボ」(代替案: 「1日1問キャリコン」「キャリコン合格チャンネル」)
- **一言コンセプト**: 「スキマ時間の1問から、合格まで最短距離で伴走する」
- **ターゲット**: 働きながらキャリアコンサルタント国家試験を目指す30〜50代(学習時間が細切れ)
- **提供価値**: ①毎日続けられる一問一答(Shorts) ②要点を体系化した講義(長尺) ③直前期の総仕上げ(再生リスト)

## 3. 3段ロケット構造(アルゴリズム対応の中核)

```
Shorts(発見)          長尺(定着)              再生リスト(セッション貢献)
一問一答・15〜30秒  →  分野別解説・7〜10分  →  「理論家総整理」「論述対策」等の
登録者0でも露出       維持率70%を狙う密度      連続視聴でセッション延長
```

- **Shorts**: 「キャリコン一問一答」フォーマット。問題提示(3秒)→思考時間(5秒)→正解+一言解説(10秒)。完走・ループされやすい構造。週5本。
- **長尺**: 「スーパー(キャリア理論家)1人を7分で完全整理」型。冒頭30秒で「この動画を見終わると何ができるようになるか」を約束。週1本。
- **再生リスト**: 「理論家シリーズ」「過去問解説」「論述」の3本柱。動画終端で必ず次の動画へ誘導。

## 4. 命名・サムネ・タイトル規約

- タイトル: 「【キャリコン試験】」プレフィックスで検索とクラスタ認識を統一。数字を入れる(例:「シャインの3つの問いを7分で」)。
- サムネ: 白背景+大文字3〜7字+人物/理論家イラスト。「約束」だけを書き、本編で必ず履行する(満足度対策)。
- 冒頭30秒: 結論またはゴール提示から始める。自己紹介・挨拶は入れない。

## 5. KPI(最初の90日)

| 指標 | 30日 | 60日 | 90日 |
|---|---|---|---|
| Shorts視聴維持(スワイプされず視聴) | 70%以上 | 75% | 80% |
| 長尺CTR | 4%以上 | 5% | 6% |
| 長尺維持率 | 40%以上 | 50% | 55% |
| 登録者 | 100 | 500 | 1,000 |
| 投稿本数 | Shorts20本+長尺4本 | 累計48本 | 累計72本 |

判断ルール: 数値が2週連続で基準を下回ったフォーマットは、企画ではなく**冒頭30秒とサムネから**改善する(アルゴリズムの評価順序に合わせる)。

## 6. 運用体制(3層体制へのマッピング)

| 役割 | 担当 |
|---|---|
| 指示係 | ユーザー窓口・最終報告 |
| 設計係 | 企画・台本・ショットリスト作成、成果物点検(Plan/Check) |
| 実行係 | 撮影・編集・投稿・数値取得(Do/Action)。設計係のOKまで修正往復 |

週次サイクル: 月曜=設計係が企画/台本確定 → 火〜金=実行係が制作・投稿 → 日曜=数値レビューをもとに設計係が翌週計画を修正 → 指示係がユーザーへ報告。
