## 1. アルゴリズムの本質

YouTubeのおすすめシステムは「良い動画を探すシステム」ではなく、**「視聴者ごとに、その人が見続けたくなる動画を予測するシステム」**である。つまり最適化の対象は「動画」ではなく「視聴者と動画のマッチング」。この前提がすべての戦略の土台になる。

評価は大きく3系統のシグナルで行われる:

| 系統 | 具体的シグナル | 意味 |
|---|---|---|
| エンゲージメント | CTR(クリック率)、総視聴時間、コメント、共有 | 「クリックされ、見られたか」 |
| 満足度 | 視聴後アンケート、再訪問、「興味なし」ボタン、高評価/低評価 | 「見てよかったと感じたか」 |
| 関連性 | タイトル、説明文、字幕・文字起こし、画面内テキスト | 「誰に向けた動画か」 |

2026年の重要な変化として、**満足度シグナル(視聴後アンケート等)が生の視聴時間より重く評価される**ことが公式に確認されている。「釣りサムネで長く見せる」戦術は構造的に減点される時代になった。

## 2. 配信テストの4層構造

新規投稿は一気に全体へ配信されるのではなく、段階的にテストされる:

1. **第1層**: ニッチが一致する少数の視聴者(約10〜100人)にテスト配信
2. **第2層**: 同ニッチのより広い層へ拡大
3. **第3層**: 隣接トピックの視聴者へ拡大
4. **第4層**: プラットフォーム全体のおすすめへ

各層でCTR・維持率・満足度が基準を超えると次の層へ進む。**初動で「誰向けの動画か」をアルゴリズムに誤解させないこと**(タイトル・サムネ・冒頭30秒の一貫性)が、第1層突破の鍵。

## 3. 数値基準(長尺動画)

- **CTR**: 健全ラインは4〜10%。4%未満はサムネ/タイトルの敗北。
- **維持率**: 40%を下回るとCTRが高くても配信が抑制される。「7分×維持率70%」は「10分×維持率35%」に勝つ。**長さより密度**。
- **セッション貢献**: 2026年の長尺ランキングで最重要のシグナル。自分の動画がYouTube滞在セッションをどれだけ延長したか。→ **単発動画よりシリーズ・再生リスト設計が構造的に有利**。
- 2026年2月のブラウズフィード刷新で、パーソナライズが「大分類トピック」から「視聴履歴クラスタ」ベースに変更。→ チャンネルの**テーマ一貫性**がこれまで以上に重要(雑多なチャンネルはクラスタに載らない)。

## 4. Shortsアルゴリズム(長尺とは別システム)

- Shortsのフィードは長尺のおすすめとは**独立したシステム**で動く。
- 評価軸: **「視聴 vs スワイプ離脱」率**、平均視聴時間、視聴完了率(APV)、満足度。
- **チャンネル登録者数に依存しない**。登録者0でもShorts棚経由で数百万リーチが可能 → **新規チャンネルの最速成長経路はShorts**。
- 15〜30秒は完走・ループされやすく有利。
- 2026年1月から検索結果にShorts専用フィルタが追加され、Shortsが検索の一級市民になった → **Shortsにも検索キーワード設計が有効**。
- 投稿頻度は週3〜5本が持続可能ライン(TikTok的な大量投稿は不要)。

## 5. 分析から導かれる勝ち筋(新規チャンネル向け)

1. **ニッチを1つに固定する** — 視聴履歴クラスタに載るため、テーマの一貫性が生命線。
2. **Shortsで発見 → 長尺で定着 → 再生リストでセッション貢献**、の3段ロケット構造。
3. **冒頭30秒に全投資** — 第1層テストの生死は維持率初動で決まる。
4. **サムネ・タイトルは「約束」、本編は「約束の履行」** — 満足度アンケート時代の大原則。
5. **シリーズ化前提の企画** — 「次も見る理由」が構造に組み込まれた企画だけを作る。
6. **検索需要のあるキーワードを握る** — 新規チャンネルはブラウズより検索・Shortsが初期流入の主戦場。
