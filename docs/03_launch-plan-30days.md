# 立ち上げ30日プラン(初動コンテンツ計画)

前提: `02_channel-design.md` の3段ロケット構造を実行に落とすための初動計画。

---

## 週次スケジュール

| 週 | Shorts(週5本) | 長尺(週1本) |
|---|---|---|
| 1週目 | 一問一答 #1〜5(キャリア理論・頻出) | 「キャリコン試験の全体像を7分で(勉強順ロードマップ)」 |
| 2週目 | 一問一答 #6〜10(スーパー/シャイン) | 「スーパーのキャリア発達理論を7分で完全整理」 |
| 3週目 | 一問一答 #11〜15(労働法規・頻出) | 「シャインの3つの問い(キャリアアンカー)を7分で」 |
| 4週目 | 一問一答 #16〜20(カウンセリング理論) | 「ロジャーズの来談者中心療法を7分で」 |

- 長尺は最初から再生リスト「理論家総整理シリーズ」に格納し、終端カードで次回作へ誘導。
- Shortsの説明欄に長尺・再生リストへのリンクを固定挿入(Shorts→長尺の導線)。
- 既存の一問一答クイズアプリ(index.html)の問題データをShorts台本の元ネタとして使用し、概要欄からアプリへ誘導。

## Shorts台本テンプレート(15〜30秒)

```
[0-3秒]  問題テロップ+読み上げ「キャリコン一問一答。◯◯とは?」
[3-8秒]  選択肢表示+カウントダウン(思考時間)
[8-18秒] 正解表示+一言解説(覚え方のフック1つだけ)
[18-20秒]「明日も1問。登録して毎日続けよう」→ 冒頭にループ
```

ポイント: 解説を欲張らない(1フックのみ)。完走率とループがShortsの生命線。

## 長尺台本テンプレート(7〜10分)

```
[0:00-0:30] 約束提示「この動画を見終わると、◯◯を自分の言葉で説明でき、過去問◯問が解けます」
[0:30-1:00] 全体マップ(この理論の試験での出題位置)
[1:00-6:00] 本編3ブロック(概念→頻出ポイント→ひっかけパターン)
[6:00-7:00] 過去問1問をその場で解く(学習効果の実感=満足度)
[7:00-    ] 次の動画への橋渡し(再生リスト誘導)
```

## チェックリスト(設計係の点検項目)

- [ ] タイトル・サムネ・冒頭30秒が同じ「約束」をしているか
- [ ] 維持率グラフの脱落点(公開48時間後)を確認したか
- [ ] Shortsは20秒以内に収まっているか/ループ接続が自然か
- [ ] 再生リストへの格納・終端カード設定を忘れていないか
- [ ] 説明欄にキーワード(キャリアコンサルタント試験、学科、過去問 等)が自然に入っているか

## 30日後のレビュー観点

1. Shortsの「視聴vs スワイプ」率70%未満のもの → 冒頭3秒の問題提示を改善
2. 長尺CTR4%未満 → サムネ文言をABテスト(YouTube公式のサムネテスト機能を使用)
3. 維持率40%未満 → 脱落点直前のブロックを削る(長さより密度)
4. 伸びたテーマの隣接トピックへ横展開(第3層=隣接クラスタへの拡大を狙う)
