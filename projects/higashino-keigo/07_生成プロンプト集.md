# 生成プロンプト集（キャラクター登録／コピペ用）

承認後、この8本をそのまま `generate_image` に流します。**モデル：`nano_banana_2`（Nano Banana Pro） / `aspect_ratio: 16:9` / `count: 1`**。

## 技術判断：Soul ではなく Element で登録します

| | Soul（`show_characters` action=train） | **Element（`show_reference_elements` action=create）** |
|---|---|---|
| 1生成に使える人数 | **1人だけ** | 複数OK（`<<<id>>>`を並べられる） |
| 必要な参照画像 | 1体あたり5〜20枚 | **1枚** |
| 所要時間 | 1体あたり約10分 | 即時 |

**Elementを選びます。決定的な理由は、複数人が同時に映るショットがあることです。**
#009 父＋少年／#017 姉＋弟／#030 妻＋本人／#061 雪穂＋亮司。Soulは1生成に1人しか使えないため、これらが作れません。

副次的に、Soulなら参照画像が8体×5〜20枚＝40〜160生成必要になりますが、Elementなら**画像生成は8回だけ**で済みます。ご指示の「画像作成はキャラクター登録のみ」にも合います。

### 手順
```
① generate_image ×8（下記プロンプト）
② show_reference_elements action=create（①のjob_idをmedias[].idに渡す／type='image_job'）
③ 返ってきた element_id を下表に記録
④ 動画生成時は params.prompt に <<<element_id>>> を埋め込む
```
