## 全生成にスタイルキーを添付します（最重要）

```json
medias: [ { "value": "1492dc8e-4e92-4c22-81e8-b9aa1f26e7d9", "role": "image" } ]
```

プロンプトの文章より**キー画像のほうが強く効きます。** これを外すと8体の画風がバラつきます。

> プリセット本体は9:16です。動画クリップは**キー画像から画角を継承する**ため、そのまま使うと本編が縦になります。**16:9のキーを作り直し済み**なので、必ず上のIDを使ってください。

## 登録方式：Element

複数人が同時に映るショット（#009 父＋少年／#017 姉＋弟／#030 妻＋本人／#061 雪穂＋亮司）があるため、1生成に1人しか使えないSoulではなくElementを使います。`soul_2`（0.12クレジット）はElement非対応のため使いません。

```
① generate_image ×8（下記プロンプト＋スタイルキー添付）
② show_reference_elements action=create（①のjob_idを medias[].id に渡す／type='image_job'）
③ 返ってきた element_id を下表に記録
④ 以降の生成では prompt に <<<element_id>>> を埋め込み、スタイルキーも併せて添付
```

**8体すべて「役の衣装なし・素の状態」で登録します。** 白衣・コート・学生服・作業服はショット側で着せます。
