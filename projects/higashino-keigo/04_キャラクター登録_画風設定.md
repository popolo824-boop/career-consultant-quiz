基準：Higgsfield公式プリセット **Editorial Motion Graphics**
- preset id `56fc6472-33b7-45dc-83ff-80c71d40aec6`
- **スタイルキー（16:9・生成済み）job id `b0934bed-1b78-4ea5-8b9e-7002c40c0692`**
- プリセット元画像 media_id `94558476-1ab2-46a5-9a2f-7d5d0f8ce4d2`（9:16のため直接は使わない）

> プリセットは9:16です。動画クリップは**キー画像から画角を継承する**ため、そのまま使うと本編が縦になります。**プリセットを参照した16:9のスタイルキーを作り直し済み**で、以降はそちらを全生成に添付します。

## 0. 絶対ルール

1. **全生成に「スタイルキー」を添付します。** これが画風統一の要です。プロンプトの文章より、キー画像のほうが強く効きます。
   ```
   medias: [ { value: "b0934bed-1b78-4ea5-8b9e-7002c40c0692", role: "image" } ]
   ```
2. **既存写真をアップロードして生成することを禁止。** 特定写真の翻案になり著作権リスクが生じます。**言葉による特徴記述だけ**で人物を作ります。
3. **画面内に文字を生成させません。** 看板・新聞・カレンダー・チャートの数字は**すべて白紙で生成**し、テロップは編集で後から重ねます。AI生成の日本語は必ず崩れます。Higgsfieldの自動字幕も欧文フォントのみなので使いません。
4. **Voxの識別可能なブランド要素は使いません。** 黄×黒×白の配色、同一書体、ロゴ、番組フォーマット。**手法は参照しますが、実在メディアのアイデンティティは模倣しません。** 下の独自パレットを使います。
5. **架空の登場人物は、その役を演じた俳優に寄せて描きます。** 湯川学→福山雅治さん／加賀恭一郎→阿部寛さん／雪穂→綾瀬はるかさん。役柄と本人は同じ登録キャラを兼用（第7節）。
6. **ご家族（父・姉・妻）は、特定できないように描きます。** お顔が公表されていない私人です。
7. 人物以外の実写素材はCC0のみ。**デュオトーン処理**で馴染ませます（第8節）。

### 動画は `kling3_0_turbo` を使います

| モデル | 10秒あたり | Explainer合成 |
|---|---|---|
| `gemini_omni`（Explainer標準） | 30 | ○ |
| **`kling3_0_turbo`（採用）** | **15** | **○** |
| `veo3_1_lite` | 8（最大8秒） | ✕（10秒グリッドに乗らない） |

`kling3_0_turbo` は**10秒ちょうど出せて `start_image` に対応**しているため、`explainer_video` の自動合成とナレーション同期がそのまま使えます。`gemini_omni` の半額なので、同じ予算で**10秒 → 20秒**に伸びます。

**start_image には承認済みの静止画を渡します。** 「スタイルを似せる」ではなく「その絵から動きだす」ので、画風がブレません。
