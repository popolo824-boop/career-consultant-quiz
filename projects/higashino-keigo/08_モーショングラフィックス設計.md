# モーショングラフィックス設計（チャート3本）

Vox系の核は配色や書体ではなく、**数字を絵にして見せること**です。本編で作り込むのはこの3本だけ。残りは静止テロップで処理します（8/1公開を守るための判断／`01_企画書.md` 第3.7節）。

**共通仕様**
- 16:9 / 背景は生成り `#F2EDE3` のフラットな面
- バー・線・文字は 墨 `#2E2A26`、**減衰・落選は 灰 `#8C8375`**、副情報は 淡茶 `#C2A279`
- **朱 `#C0472C` は各チャートに1点だけ。** 「そこが答え」という場所にしか置かない
- イージングは ease-out のみ。バウンス・オーバーシュート禁止（追悼企画）
- 数字は特大。ラベルは小さく。**画面に出す情報は、ナレーションが今しゃべっていることだけ**

## チャート① 「14年」

**使用ショット：#004（5秒・導入）／#051（5秒・再登場）／#052（10秒・重ね合わせ）**

本編の主線を1枚で示す図です。#004で提示し、第五章で回収します。

### レイアウト
画面中央に1本の水平な帯。左端に `1985`、右端に `1999`。帯の中は空白のまま。

```
1985 ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━● 1999
 江戸川乱歩賞受賞                                    『秘密』『白夜行』
        └────────── 14年 ──────────┘
```

### 動き

| ショット | 秒 | 動き |
|---|---|---|
| #004 | 5s | 左端の点が打たれる（0.5s）→ 帯が右へ伸びきる（2.5s）→ 中央下に「14年」が出る（1s）→ 静止（1s）。**帯の中は空白のまま。ここでは何も起きなかったことを見せる** |
| #051 | 5s | 同じ帯を再提示。帯の上に年の目盛りを1年ずつ刻む（1986…1998）。刻み終えて静止 |
| #052 | 10s | **本チャートの核。** 同じ14年の帯の下に、2本の比較帯を並べて出す |

### #052 の重ね合わせ（第五章の核）

ナレーション「新卒で入った人が、三十代半ばになります。子どもが生まれて、小学校を卒業する。それだけの年月を、結果の出ない仕事に注ぎ続けるということです。」

```
1985 ●━━━━━━━━━━━ 14年 ━━━━━━━━━━━● 1999    ← 東野圭吾
     ●━━━━━━━━━━━━━━━━━━━━━━━━━━● 　　       新卒入社 → 30代半ば
     ●━━━━━━━━━━━━━━━━━━━━━━━━━━● 　　       子どもが生まれる → 小学校卒業
```

- 2本目・3本目は灰の帯で、ナレーションに合わせて1本ずつ伸ばす
- 3本が同じ長さで揃った瞬間に**全体を1秒静止**。ここが効きどころ
- **朱は使いません。** このチャートは「報われなかった時間」の図なので、点灯させない

## チャート② 「直木賞」── 本編最大の見せ場

**使用ショット：#065（11秒・候補が並ぶ）／#066（7秒・五回）／#070（15秒・受賞）**

第七章のクライマックス。5連敗が積み上がり、6本目だけが朱で点灯します。

### レイアウト
縦に6行。左に作品名、右へバーが伸びる。

```
　秘密        ━━━━━━━━━━━━━━━ ✕     ← 灰 #8C8375
　白夜行      ━━━━━━━━━━━━━━━ ✕     ← 灰 #8C8375
　片想い      ━━━━━━━━━━━━━━━ ✕     ← 灰 #8C8375
　手紙        ━━━━━━━━━━━━━━━ ✕     ← 灰 #8C8375
　幻夜        ━━━━━━━━━━━━━━━ ✕     ← 灰 #8C8375
　容疑者Ｘの献身 ━━━━━━━━━━━━━━━ ●     ← 朱 #C0472C
```

### 動き

| ショット | 秒 | 動き |
|---|---|---|
| #065 | 11s | ナレーションが作品名を読むのに合わせ、上から1行ずつバーが伸びる → 伸びきった瞬間に灰に沈み、右端に ✕ が付く。**5回繰り返す。同じ動きを繰り返すことが効果** |
| #066 | 7s | 5本が灰色で並んだ状態。中央に数字 **「5」** を特大で重ねる。他は動かさない |
| #070 | 15s | 6行目のバーが伸びる（他5本は灰色のまま）→ **伸びきった瞬間に朱 `#C0472C` で点灯**（0.3s、フラッシュさせない）→ 下部にテロップ「2006年1月　第134回直木三十五賞」→ 静止 |

### 表示上の注意（ファクトチェック由来）

**5点の落選作については、回次を画面に出しません。作品名だけを出します。**
`06_ファクトチェック表.md` で、『秘密』＝第120回と『手紙』＝第129回は照合が弱い（prizesworldの一覧からの推定を含む）ためです。チャートは文字より強く伝わるので、裏取りの弱い数字を画面に置きません。

**回次を出すのは6行目『容疑者Ｘの献身』の第134回だけ。** これは各社報道と一次情報で確定しています。

## チャート③ 「1億部」

**使用ショット：#081（12秒）**

### レイアウト
画面下から積み上がる縦のバー。到達点に朱の水平線を1本。

```
                    ┃
                    ┃  ━━━━━━ 1億部（朱の到達線）
                    ┃
                    ┃
                    ┃
        ────────────┸────────────
```

### 動き
1. バーが下から立ち上がる（4s、ease-out）
2. 到達点で **朱の水平線**が左右に伸びる（1s）
3. テロップ：**「国内累計 1億部突破」**／小さく「2023年4月3日時点・電子書籍を含まない紙の書籍のみ」（2s）
4. 静止（5s）

### 続く#082（世界地図）との接続
#082 は静止画（フラットな世界地図）です。チャート③のバーを画面外へ送り、地図へ切り替えます。地図上のテロップは「37の国と地域／推定 約6,800万部」「国内外あわせて 推定 約1億6,800万部」。

**数字の出典はすべて講談社と文藝春秋の一次発表**（`06_ファクトチェック表.md` ◎判定）。この3つは安心して画面に出せます。
