## 1. 最重要判断：企画方針を「追悼特集」に変更した

**リサーチの結果、東野圭吾さんは2026年7月23日未明に大腸がんのため逝去（68歳）、7月27日に講談社と本人の公式アカウントが発表していることが確認できました。**
（NHK・テレビ朝日系ANN・スポーツ報知・オリコン・大阪公立大学の追悼の辞などで一致）

これは企画の前提を変える事実です。当初の「有名人の人生をストーリー仕立てで紹介」という枠は維持したまま、**追悼特集として設計し直しました。** 理由は3つです。

1. **需要**：訃報から1週間。検索・視聴需要が年間で最も高い局面にあります。
2. **タイミングの二段構え**：2026年8月5日に最新長編『永遠の記憶』（副題「ガリレオ、最後の謎」）が刊行予定。訃報需要と新刊需要が重なる、極めて稀な窓です。
3. **チャンネル資産**：追悼企画は一過性ですが、「人生を丁寧に辿る」構成にすれば、10年後も再生される恒久コンテンツになります。速報型の切り抜き動画とは戦う場所を変えます。

### 公開スケジュール（CEO決定）
| 日程 | 内容 |
|---|---|
| 7/31 | ショート①「本を読まない少年」投稿 |
| 8/1 | **本編15分 公開** |
| 8/2 | ショート②「売れない14年」投稿 |
| 8/5（新刊発売日） | ショート③「最後の謎」投稿＋本編を固定コメントで再訴求 |

訃報から日が経つほど価値が落ちます。**8/1公開を死守。** 完璧より速度を優先します。

## 2. ターゲットと勝ち筋

- **主ターゲット**：40〜65歳。東野作品をドラマ・映画で知り、原作も何冊か読んでいる層。追悼で「あの人はどんな人生だったのか」を知りたい。
- **副ターゲット**：25〜39歳。「売れない14年」「5回落選」に自分を重ねる、キャリアに悩む層。ショート動画で獲る。

**勝ち筋＝「作品紹介」をしないこと。** 追悼動画の99%は代表作の羅列になります。本企画は徹底して**「売れなかった14年」と「直木賞5回落選」を主線**に置きました。視聴者が自分の人生と重ねられる物語だけが、15分見られます。

**核となる引用**（2006年1月・直木賞受賞会見）
> 「六回目、七年かかったんですけど、正直、強がりでなくすごく楽しい七年でした。落ちるたびにやけ酒飲んで、みんなで選考委員の悪口言って、普通の人はできないおもしろいゲームをやったなという。」

この一言のために15分を組みました。第七章がクライマックスです。

## 3. タイトル・サムネイル

### タイトル案（A推奨）
- **A：【追悼】東野圭吾 ─ 売れない14年、直木賞5回落選。それでも彼は書き続けた**
- B：東野圭吾の生涯｜本を読まない少年が、1億部の作家になるまで
- C：【追悼 東野圭吾】エンジニアだった男が、日本一売れる小説家になった日

A採用理由：数字（14年／5回）が具体的で、感情のフックが2つ入る。「追悼」は冒頭に置く（検索意図と一致するため）。

### サムネイル（16:9・1280×720）
- 左2/3：Editorial Motion Graphicsの壮年期の肖像（`CHAR_HK_C`／登録画をそのまま流用。右側に余白を確保済み）。**俳優3名の肖像は使わない**
- 右：大きな白文字「**売れない14年**」／下に小さく「直木賞 5回落選」
- 背景：煉瓦色 `#A8785C` の面。**朱 `#C0472C` はサムネイルには使わない**（本編の「点灯」の意味が薄まるため）
- 顔に矢印・驚愕表情・赤丸などの煽り装飾は**禁止**。故人の追悼企画としてチャンネルの信頼を損なう。

## 3.5 画風の全面変更（Vox系へ）

**旧「古い羊皮紙にインクと水彩」→「フラットな編集イラスト＋モーショングラフィックス」に変更しました。**

### 判断の根拠

`get_cost` で実測した単価が、方針を決めました。

| | 実測単価 |
|---|---|
| 画像 `soul_2`(2K) | **0.12クレジット** |
| 動画 `veo3_1_lite`(最安・音声オフ) | 1.0クレジット/秒 |

**10秒の動画1本が、静止画83枚ぶんです。** 全92ショットを動画化すると741クレジット必要で、残高109.49に対して632不足でした。

Vox系の解説動画は**そもそもAI動画を使わず、静止画とグラフィックスで成立しています。** つまり画風の変更は、予算制約への妥協ではなく、**制約と目的が一致する解**でした。

| | 動画本数 | クレジット |
|---|---|---|
| 旧方針（全ショット動画化） | 70本 | 741（**632不足**） |
| **新方針（Vox系・静止画のみ）** | **0本** | **約72（チャージ不要・残高109.49）** |

※当初は画像単価0.12の `soul_2` で約17と見込んだが、同モデルはElement（キャラの顔を固定する仕組み）に非対応。キャラの一貫性を優先し、Element対応で最安の `seedream_v4_5`（1クレジット）に統一して72に修正した。

### 副次的な利点

1. **画風がブレない。** AI動画は紙の質感を勝手に動かし、線を溶かします。静止画なら8体の顔も画風も1枚ずつ確定でき、追悼企画で最も怖い「別人に見える」事故が起きません
2. **数字が主役になる。** 本企画は「14年」「5回落選」「1億部」が主線です。チャートで見せるのが最も強い
3. **納期。** 動画生成の待ち時間とリテイクが消え、8/1公開の確度が上がります

### 移植しないもの

- **Voxの配色（黄×黒×白）・書体・ロゴ・番組フォーマット。** 手法は参照しますが、**実在メディアのブランドアイデンティティは模倣しません。** 独自パレット（`04`第1節）を使います
- 実写アーカイブ写真（著作権。人物はイラストで通す方針は変更なし）
- 全編の高速カット（追悼のトーンが壊れる）。速くするのは情報密度の高い章だけ

### チャートは3本に絞る

7か所の候補から3本だけ作り込み、残り4か所は静止テロップで処理します（`08_モーショングラフィックス設計.md`）。8/1を守るための判断です。

**優先度は ②直木賞 → ①14年 → ③1億部。時間が足りなくなったら③から静止テロップへ落とし、②だけは死守します。**

## 3.6 画風を「ペーパージオラマ」に確定（最終）

参考動画（https://youtu.be/FP8lH9Lekco ／解析は `09_参考動画分析.md`）を受け、**ペーパージオラマ**に確定しました。Higgsfield公式プリセット **Paper Diorama**（explainer preset id `83d276f6-e3aa-49b8-82f2-1a0bb7d0a370`）が基準です。

### 決めたこと

| 論点 | 決定 |
|---|---|
| 画風の適用範囲 | **全編で統一。** 場所によって絵柄を変えると、Vox系の生命線である一貫性が崩れる |
| 「重要な箇所だけ」の対象 | **動かすかどうか。** 動画にするのは冒頭の掴み4カット（#002 #003 #005 #006／34秒）だけ |
| パレット | **生成り・茶・セピアに振り直し。** 旧・紺／インディゴは廃止。朱は `#B4462A` に変更し、「点灯」の設計は維持 |
| 字幕・テロップ | **すべて後付け。** 生成時に文字を一切焼き込まない |

### なぜ「動かすのは冒頭だけ」なのか

参考動画でペーパージオラマが動いているのは**冒頭31秒だけ**です。残り7分はVTuberと棒人間アニメで、ジオラマは掴みに集中投下されています。しかも**あの作例は1分尺**で、本企画15分36秒とは尺が15倍違います。全編アニメ化は996クレジット必要で、残高108.37に対し888不足でした。

真似すべきは「全編動かすこと」ではなく、**動かす場所を絞る判断**のほうです。視聴維持率は冒頭15秒で決まるので、予算はそこに置きます。

**ペーパージオラマは層構造の画風なので、静止画を2〜3層に切ってパララックスをかけるだけで実際に奥行きが動きます。** フラット画より静止画に向いており、この乗り換えは相性が良い。

### 字幕・テロップは完全に後付け

- 生成プロンプトで**文字の生成を全面禁止**。看板・新聞・カレンダーは**白紙で生成**し、年号や見出しは編集でその面に載せる
- **Higgsfieldの自動字幕機能は使わない。** フォントが欧文のみで日本語が崩れる（参考動画内でも問題として語られていた）
- ナレーションは別トラック。テロップ・チャート・注釈はすべて編集工程

### 収支

| 項目 | クレジット |
|---|---|
| キャラ登録 8体 | 8 |
| 本編の静止画 64枚 | 64 |
| 動画 34秒 | 34 |
| **合計** | **106** |
| 残高 | 108.37 |
| **差** | **+2.4** |

**リテイク余力がほぼありません。** 静止画のリテイクが要る場合は、動画を#003と#006の16秒に絞って18クレジット浮かせます。

## 3.7 画風を「Vox風＝Editorial Motion Graphics」に確定（最終）

**「Vox風」とは Editorial Motion Graphics のことです。** 参考動画の中でもこのスタイルが「Voxが広めた解説動画の様式」として紹介されていました。Higgsfield公式プリセットとして用意されています。

| 項目 | 値 |
|---|---|
| プリセット | Editorial Motion Graphics `56fc6472-33b7-45dc-83ff-80c71d40aec6` |
| **スタイルキー（16:9・生成済み）** | **`1492dc8e-4e92-4c22-81e8-b9aa1f26e7d9`** |
| パレット | 生成り `#F2EDE3` ／ 墨 `#2E2A26` ／ 淡茶 `#C2A279` ／ 煉瓦色 `#A8785C` ／ 灰 `#8C8375` ／ **朱 `#C0472C`** |

### 画角の落とし穴を1つ潰しました

**プリセット本体は9:16（縦）です。** 動画クリップは**キー画像から画角を継承する**仕様なので、そのまま使うと本編が縦になります。プリセットを参照した**16:9のスタイルキーを作り直し**、以降の全生成にはそちらを添付します。

### 動画モデルは `kling3_0_turbo`

「Explainerの仕上がり」は4要素に分解でき、そのうち3つは動画モデルと独立しています。

| 要素 | 動画モデル依存 |
|---|---|
| 画風の統一 | ✕（`start_image` に承認済み静止画を渡せば固定される） |
| ナレーション自動生成（`seed_audio`） | ✕ |
| クリップ＋音声の自動合成（`explainer_video`） | ✕（**クリップのjob idを受け取るだけでモデルを問わない**） |
| 10秒グリッド | ○ |

| モデル | 10秒あたり | 10秒グリッド |
|---|---|---|
| `gemini_omni`（Explainer標準） | 30 | ○ |
| **`kling3_0_turbo`（採用）** | **15** | **○** |
| `veo3_1_lite` | 8 | ✕（最大8秒） |

`kling3_0_turbo` は10秒ちょうど出せて `start_image` に対応するため、**Explainerの自動合成とナレーション同期をそのまま使いながら、`gemini_omni` の半額**で済みます。同じ予算で10秒→20秒。

## 6. 制作フロー

```
① 画像生成 ×8（キャラクターの基準画）→ 07_生成プロンプト集.md（8クレジット）
② Elementとして登録（8体）            → 07 の手順
③ 登録後の目視確認                    → 04 第9節
④ 本編の静止画64枚を生成              → 05_ショットリスト.md（64クレジット）
④' 冒頭2ブロックを動画化（20秒）      → 04 第9節（30クレジット・kling3_0_turbo）
⑤ 実写素材をデュオトーン処理して合流  → 04 第8節／05 の素材台帳
⑥ チャート3本を制作                   → 08_モーショングラフィックス設計.md
⑦ ナレーション収録（TTS or 人）
⑧ 編集（動きはすべてここで作る）→ ショート3本切り出し
```

**動画は冒頭2ブロック20秒のみ。想定クレジットは約104です（残高105.37・チャージ不要）。**

キャラクター登録は**8体**です。東野圭吾さん3体（少年期・青年期・壮年期）＋父＋小峰元＋役柄兼俳優3体（湯川学／福山雅治さん・加賀恭一郎／阿部寛さん・雪穂／綾瀬はるかさん）。

東野圭吾さんを1体で全年代カバーすると顔が破綻し、追悼企画で最も避けたい「別人に見える」事故が起きます。ここは3体必要です。

一方、**役柄と俳優本人は同じ顔なので1体で兼用します**（衣装を着せるか外すかの違いだけ）。この統合で11体→8体に減りました。

登録後、`04`第8節の**目視確認（狙った俳優として認識できるか／衣装あり・なしで同一人物に見えるか／ご家族が特定の人に見えていないか）を通すまで、動画生成に進まないこと。**
