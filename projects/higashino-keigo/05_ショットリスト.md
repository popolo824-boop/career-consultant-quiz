# ショットリスト・動画生成プロンプト（16:9）

**ナレーション1ブロック=1ショットで構成。** 語りの文脈が変わるところで必ず絵が変わります。

|---|---|
| 総ショット数 | **92**（＋タイトルカード／エンドカード） |
| 合計尺 | 936秒 = **15分36秒** |
| 平均ショット尺 | 10.2秒 |
| 最短 / 最長 | 5秒 / 21秒 |
| 尺の算出 | ナレーション文字数 ÷ 6.2字/秒 ＋ ブロック間の間0.4秒（下限5秒） |

### 共通ルール

- 全生成プロンプトの末尾に `04_キャラクター登録_画風設定.md` の **`STYLE_FLAT`** を必ず付与（表内では `+STYLE_FLAT` と表記）
- **生成するのは静止画だけ。** 表内の「編集：」以降が、編集側で付ける動きの指定です
- 動きは全編ゆっくり。ズームは最大1.1倍まで。手ぶれ演出は禁止
- **文字・数字を画面内に生成させない**（AIの日本語は必ず崩れる。文字はすべて編集側のテロップとチャート）
- **朱 `#C4452E` は「意味のある1点」にしか使わない。** 使用箇所は `04` 第1節の規律表。第九章（#085-092）には入れない
- 実写素材は**デュオトーン処理**（Ink `#141B2E`／Paper `#F5F2EC`）で統一し、切り抜いてフラットな色面に置く。手順は `04` 第8節
- **ナレーションに名前が出る人物は、すべて顔を描きます。** 登録キャラ8体の内訳は `04_キャラクター登録_画風設定.md` 第2節
- **架空の登場人物は、その役を演じた俳優に寄せて描きます。** 湯川学→福山雅治さん／加賀恭一郎→阿部寛さん／雪穂→綾瀬はるかさん。役柄と本人は同じ登録キャラを兼用し、**衣装と表情だけを切り替えます**
- この3体には使用範囲の制限があります（サムネイル・ショート1枚目には使わない）。`04` 第7節を必ず確認
- ご家族（父・姉・妻）と店の客は、**特定の人物に見えないように描く**（お顔が公表されていない私人のため）
- 【R】は生成コスト削減のためだけでなく、**同じ絵を再登場させて意味を繋ぐ演出**として設計しています（例：#056は#017の高校生の読書を再挿入して「原点」を思い出させる）
