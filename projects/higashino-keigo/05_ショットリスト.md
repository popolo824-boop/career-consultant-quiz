# ショットリスト・動画生成プロンプト（16:9）

**ナレーション1ブロック=1ショットで構成。** 語りの文脈が変わるところで必ず絵が変わります。

| 項目 | 値 |
|---|---|
| 総ショット数 | **92**（＋タイトルカード／エンドカード） |
| 合計尺 | 936秒 = **15分36秒** |
| 平均ショット尺 | 10.2秒 |
| 最短 / 最長 | 5秒 / 21秒 |
| 尺の算出 | ナレーション文字数 ÷ 6.2字/秒 ＋ ブロック間の間0.4秒（**下限5秒**：AI動画の最小クリップ長に合わせる） |

### 種別と本数

| 種別 | 内容 | 本数 |
|---|---|---|
| 【A】 | 登録キャラ使用のAI動画（CHAR_HK_A/B/C） | 16 |
| 【M】 | 人物なしのAI動画（画風のみ） | 54 |
| 【S】 | 実写フリー素材（CC0／商用可） | 14 |
| 【R】 | 既生成クリップの再利用（トリミング・速度変更・重ね） | 8 |
| | **新規AI生成 = 70本** | |

### 共通ルール

- 全AI生成プロンプトの末尾に `04_キャラクター登録_画風設定.md` の **`STYLE_PARCHMENT`** を必ず付与（表内では `+STYLE` と表記）
- カメラワークは全編「ゆっくり」。ズームは最大1.1倍まで。手ぶれ演出は禁止
- **文字・数字を画面内に生成させない**（AIの日本語は必ず崩れる。文字はすべて編集側のテロップ）
- 実写素材はセピア寄りにグレーディングして羊皮紙トーンに寄せる
- 【R】は生成コスト削減のためだけでなく、**同じ絵を再登場させて意味を繋ぐ演出**として設計しています（例：#056は#017の高校生の読書を再挿入して「原点」を思い出させる）
