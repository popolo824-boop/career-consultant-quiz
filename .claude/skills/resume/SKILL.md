# 作業の再開

前回セッションのチェックポイントから作業を続きから再開する。

## 手順

1. 最新の状態を取得する:
   ```bash
   git fetch origin
   git status
   ```
   - リモートの作業ブランチが進んでいる場合は pull する。

2. `.claude/session-state.md` を読む。

3. 「現在のタスク」と「次のステップ」を確認する:
   - **次のステップが残っている場合**: ユーザーに一言で再開内容を伝えたうえで、そのまま作業を続行する。
     完了したステップは随時 session-state.md から消し込む。
   - **「なし(完了)」の場合**: 再開すべき作業がないことを伝え、新しい指示を待つ。

4. 作業を進めたら、通常どおりサブタスク完了ごとにチェックポイント(/checkpoint と同じ手順)を取る。

5. すべて完了したら `.claude/session-state.md` の「現在のタスク」を「なし(完了)」に更新し、
   コミット&プッシュして報告する。
