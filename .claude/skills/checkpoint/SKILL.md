# チェックポイントの作成

現在の作業状態を保存し、どのセッションからでも再開できるようにする。

## 手順

1. `.claude/session-state.md` を以下の内容で更新する:
   - **最終チェックポイント**: 今日の日付と現在の作業ブランチ名
   - **現在のタスク**: いま進行中のタスク(なければ「なし(完了)」)
   - **完了した作業**: このセッションで完了した項目を追記
   - **次のステップ**: 前提知識ゼロの新しいセッションがそのまま再開できる粒度で書く
     (対象ファイルと行番号、やりかけの変更内容、残りの手順、確認方法)
   - **メモ・既知の問題**: ハマりどころ、未解決の問題、判断の背景

2. すべての変更をコミットしてプッシュする:
   ```bash
   git add -A
   git commit -m "checkpoint: <作業内容の要約>"
   git push -u origin <現在のブランチ>
   ```
   - プッシュがネットワークエラーで失敗したら 2s, 4s, 8s, 16s の間隔で最大 4 回リトライする。
   - main ブランチ上にいる場合は先に作業ブランチを切ること。

3. ユーザーに以下を簡潔に報告する:
   - チェックポイントを保存した旨とコミットハッシュ
   - 中断した場合、リセット後に「/resume」または「続きを再開して」で再開できること
