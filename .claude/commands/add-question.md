第 `$1` 回の問 `$2` を `index.html` の `QUIZ_DATA` に追加してください。

追加する内容: $ARGUMENTS

## 手順

1. `index.html` 内の `QUIZ_DATA["$1"]` を探し、問 `$2` が既に存在しないか確認する。
   - 既に存在する場合は上書きせず、ユーザーに差し替えるか確認する。
2. 問番号の昇順を保つ位置に、既存エントリと同じインデント・整形で挿入する。
3. 素材が不足している場合（選択肢や正答が示されていない等）は、推測で埋めずにユーザーに確認する。
4. `python3 scripts/check_quiz_data.py` を実行し、OK になることを確認する。

## データ形式

```json
"問番号": {
  "stem": "問N 設問文…",
  "choices": ["1. …", "2. …", "3. …", "4. …"],
  "answer": 2,
  "explanations": ["× …", "○ …", "× …", "× …"]
}
```

- `stem` は `"問N "` で始め、N はキーと一致させる（既存データは全角スペース混じりの表記もあるが、新規は半角スペースで統一）。
- `choices` は `"1. "` 〜 `"4. "` の連番プレフィックス付き。
- `answer` は 1 始まりの選択肢番号。
- `explanations` は `choices` と同数・同順。先頭記号は設問タイプで決まる:
  - 通常（「最も適切なものはどれか」）→ 正答が **○**、他が **×**
  - 否定形（「不適切」「誤っている」「誤りである」「適切でない」）→ 正答が **×**、他が **○**
- 解説は「なぜ正しいか／なぜ誤りか」を根拠込みで 1〜2 文。数値や調査名は素材にある通りに書き、不明な数値を創作しない。
