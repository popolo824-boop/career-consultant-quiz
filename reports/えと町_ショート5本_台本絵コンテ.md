# えと町 ショート5本 台本・絵コンテ(Gigaverse型の構成を適用)

前提(正本 `えと町/01_えと町資料.md` と、2026-10-05の作り変え節に合わせた):
- 15〜22秒、縦9:16、1カット2〜4秒の静止画が基本。動きが要るカットだけ動画生成(動画は無音で生成し、音は編集で重ねる)
- 画面内の文字は1〜3語。言葉のセリフはなし(テロップのみ)。鳴き声・環境音・BGMは後付け
- 全話にルーチェが出る。名前のある動物は1話に最大3匹
- 透かし: 下部中央に常時表示(ハンドル名は未決。仮に「@えと町」)
- 冒頭に「ゆびで〇〇」の操作指示を入れる(実際には反応しない演出。誇大表現は使わない)
- 型: 冒頭=操作指示(0〜2秒) → 背景切り替え(2〜5秒) → 3回繰り返して3回目でずらす(5〜14秒) → オチ(14〜19秒) → 1カット目に戻ってループ
- 最後の一行(かみさまの語り)は入れない版を基本。比較用に1本だけ入れた版を作る

列の読み方: 秒 / 絵 / 動き(静=静止画、動=動画生成)/ テロップ / 音

## 制作メモ
- 5本とも、15〜20秒版と30〜45秒版の2種類を作り、完走率を比較する(まずは15〜20秒版を主力)
- 各話の最後の一行(かみさまの語り)は入れない版を基本。第2本だけ入れた版を作り、共有・保存の差を比べる
- 透かしのハンドル名、ルーチェの語尾(にゃ)の使い方は未決
- 第5本はチョロの優しい面を見せる回。「嘘をつく理由」の伏線は入れない(正本の「チョロを悪役にしない」に合わせた)
- 公開タイトルには「自主制作アニメ」を付ける。タイトル案は別途作る
