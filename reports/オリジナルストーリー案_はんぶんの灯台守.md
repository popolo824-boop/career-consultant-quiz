# オリジナルストーリー案「はんぶんの灯台守」(創作案)

これは事実の報告ではなく、私の創作案。採否はこちらで決めてほしい。
鬼滅の刃・ちいかわの資料で「視聴者の心理に働きかける要素」として挙げられていたもの(批評・編集者の見立て・行動データ)を骨組みに使い、題材・世界・キャラクターは新しく作った。既存の作品と似ていないかの確認はしていない。

## 一行で
人間ではない「はんぶん」の灯台守が、毎晩、海を渡れなかった者の灯りを一つずつともす。灯りの数は増える一方で、自分の灯りだけは、ない。

## 踏襲した要素と、この作品での置き換え
| 元の作品で挙げられていた要素 | この作品での形 |
|---|---|
| 敵にも悲しい過去がある(鬼滅) | 灯台に現れる「海を渡れなかった者たち」は、怖い姿で来るが、灯りをともすと生前の一場面が1カットだけ見える。退治はしない。送る |
| 普通の人を中心に、周りに異常性を置く(鬼滅・編集者の証言) | 主人公「はんぶん」は特別な力がない。周りの来訪者と、相棒の黒い鳥が異常 |
| 短く強い言葉(両作品) | はんぶんの言葉は1〜3語だけ(「ともすよ」「いけるよ」「まだ」)。相棒の鳥が感情を翻訳する(ちいかわのハチワレの役割) |
| 働く大人の自己投影(ちいかわ) | 灯台守の仕事は「毎晩、決まった時刻に、決まった数だけ灯す」単純労働。帳面、点検表、報酬(魚一匹)がある |
| 不憫さ・応援したくなる弱さ(ちいかわ) | はんぶんは、自分が海を渡れなかった者の一人であることを知らない。視聴者だけが気づく |
| かわいさと不条理の落差(ちいかわ) | 絵柄は絵本調で丸く、来訪者は怖い。灯りをともすと、来訪者は一瞬だけやさしい姿になる |
| 説明しない余白・考察(両作品) | 「はんぶん」が何の半分なのか、最後まで説明しない。灯りの数と、海の向こうの島の灯りの数が、毎話少しずつ違う |
| 追いつける長さ(鬼滅) | 全24話で完結。1話は1〜2分 |
| 家族という普遍テーマ(鬼滅) | はんぶんを待つ者が、海の向こうにいる(第4章で分かる) |
| 参加の習慣化(鬼滅・毎週月曜のピーク) | 毎話、画面の端に「今夜の灯り: ◯個」を出す。視聴者が数を追える |
| 推しの分散(ちいかわ・鬼滅の人気投票) | 来訪者は毎話ちがう。再登場する者を数人置く |

## 世界観のルール
- 岬の灯台と、海の向こうの小さな島。島には渡れない。島の灯りは、夜だけ見える。
- 灯台守の仕事: 毎晩、「海を渡れなかった者」が一人ずつ岬に来る。灯台守が灯りをともすと、その者は海を渡っていく。
- ともした灯りは、灯台の壁に一つずつ増える(帳面にも記す)。
- 灯台守は、自分の灯りをともせない。それが「はんぶん」の意味だと、視聴者は後で気づく。

## 登場人物
| 名前 | 姿 | 役割 |
|---|---|---|
| はんぶん | 体の右半分だけが色づいた、小さな丸い灯台守 | 主人公。言葉は1〜3語。几帳面で、帳面を毎晩書く |
| クロ | 黒い海鳥 | 相棒。はんぶんの感情を、代わりに言う(「怖がってる」「嬉しいって」) |
| 来訪者たち | 毎話ちがう。影のように黒く、灯りをともすと生前の姿が一瞬見える | 海を渡れなかった者 |
| 島の灯り | 海の向こうで、夜だけ数が見える | 最後まで、誰の灯りかは描かない |

## 1話の型(1〜2分)
| 時間 | 中身 |
|---|---|
| 0〜5秒 | 「今夜の灯り: ◯個」。はんぶんが灯台の階段を上る |
| 5〜30秒 | 来訪者が来る。怖い姿。クロが怖がる。はんぶんは帳面に名前を書く(名前は来訪者が言わない。はんぶんが聞く) |
| 30〜70秒 | 灯りをともす。来訪者の生前の一場面が1カット(説明なし)。来訪者は海を渡る |
| 70〜90秒 | 壁の灯りが一つ増える。島の灯りを、はんぶんが数える。数が合わない |
| 最後 | クロの一言(「また明日」など)。帳面を閉じる |

## 章立て(全24話)
### 第1章「灯りの数え方」(1〜5話)
- 毎晩の仕事。来訪者は、魚売り、郵便配達、子ども、老いた犬、名前を言わない者。
- 伏線: 5話目の来訪者だけ、灯りをともしても渡らない。はんぶんの隣に座って、海を見る。
### 第2章「渡らない者」(6〜10話)
- 渡らない来訪者が、毎晩来る。名前は「ナギ」。クロが嫌がる。
- ナギは、はんぶんの左半分(色のない方)を、ずっと見ている。
- 伏線: ナギの生前の一場面は、灯台の階段だった。
### 第3章「帳面の最初の行」(11〜15話)
- 嵐で灯りが消える。壁の灯りが全部消え、はんぶんが一晩でともし直す。
- 帳面の最初の行は、はんぶんの字ではない。誰かが、はんぶんの名前を書いている。
- 伏線: 島の灯りが、この夜だけ一つ増える。
### 第4章「島の灯り」(16〜20話)
- ナギが、島の灯りを一つずつ指して、誰の灯りかを言う(クロが訳す)。最後の一つだけ、言わない。
- はんぶんは、島の灯りの一つが、自分を待っている灯りだと気づきかける(視聴者には分かる。はんぶんは分からない)。
### 第5章「はんぶんの灯り」(21〜24話)
- 真相(案): はんぶんは、昔、海を渡る途中で引き返した者。渡れなかった半分が灯台守になり、渡った半分が島にいる。島の最後の灯りは、もう半分の自分。
- ナギは、はんぶんを渡らせに来た者。
- 結末: はんぶんは、自分の灯りを、ナギにともしてもらう。海を渡る。灯台には、クロと、はんぶんの帳面が残る。最後のカットは、島の灯りが一つ減り、灯台の壁の灯りが一つ増える。
- 「どちらがはんぶんの灯りか」は、最後まで言わない。

## 考察の仕掛け(解釈が割れる点)
| 仕掛け | 割れる解釈 |
|---|---|
| 「はんぶん」の意味 | 体の半分/命の半分/渡れなかった半分 |
| 灯りの数が合わない | 島の数が正しいのか、壁の数が正しいのか |
| 帳面の最初の行の字 | ナギの字か、もう半分の自分の字か |
| 最後の灯り | 島に増えたのか、灯台に増えたのか |
| クロは何者か | 鳥か、見送る側の誰かか |

## 共感の設計
- 毎晩同じ仕事をする(働く人)。
- 誰かを送るばかりで、自分は送られない(人の世話をする人)。
- 言いたいことを、自分で言えない(クロが代わりに言う)。
- 自分の居場所が分からない。

## 言葉(1〜3語)
- はんぶん: 「ともすよ」「いけるよ」「まだ」「なまえは?」
- クロ: 「こわいって」「うれしいって」「また明日」
- ナギ: 言葉なし。最後に一言だけ(内容は決めない)。

## この案の限界
- 共感や考察が起きるかは、公開して見ないと分からない。
- 「踏襲した要素」は、批評家や編集者の見立てで、ヒットの原因として証明されたものではない。
- 24話、1〜2分、灯りの数などは、私の設計案。
