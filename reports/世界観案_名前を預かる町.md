# 世界観案「名前を預かる町」(創作案)

これは創作案で、事実ではない。`掛け合わせ_共感と考察の設計原則.md`(共感5条・考察5条・成長・過去と悩み)に、「感情移入」の軸を足して、一つの世界観にした。
未来1・2・3の要素(人口減少、技術の偏り、崩れて作り直す)は、設定の底に残してある。登場人物の名前は決めない。

## 三つの軸の違い(この世界での定義)
| 軸 | 何が起きるか | この世界での仕掛け |
|---|---|---|
| **共感** | 「自分のことだ」と思う | 労働、言えない言葉、守れなかった過去 |
| **感情移入** | その人物の目で世界を見る。怖さや喜びを一緒に感じる | 主人公の「知らないこと」を、視聴者も同時に知らない。視点を一人に固定する |
| **考察** | 「なぜ?」と考えたくなる | 説明しない仕組み、合わない数、放置された矛盾 |

共感は「似ている」から起きる。感情移入は「一緒にいる」から起きる。考察は「分からない」から起きる。三つは別の仕掛けで、順番は 感情移入 → 共感 → 考察。

## 一行で
人が減りすぎて名前が余った世界で、死んだ者の名前を預かり、生まれた子に渡す「預かり屋」が、誰にも渡せない名前を一つ、持っている。

## 世界の前提(未来1・2・3の底)
- 数百年前に、人口が急減した(理由は伝説の形でしか残っていない。考察の材料)。
- 今、人は少ない。町は小さく、間は空いている。空いた土地は森と水に戻っている。
- 技術は残っているが、動かせる者が少ない。動く機械は「拾い物」で、直せる者が力を持つ。
- どこかに、技術を独占する「向こう」があるらしい。誰も見たことがない。

## 名前の決まり(この世界の核)
1. **人は少ないので、名前は余っている。** 死んだ者の名前は消えず、「預かり屋」に預けられる。
2. **生まれた子は、名前を持たない。** 5歳になると、預かり屋から、死んだ者の名前を一つ渡される。
3. **名前には、前の持ち主の記憶が一つだけ付いている。** 渡された子は、その一つの記憶を、自分のもののように覚えている。
4. **預かり屋は、名前を渡す相手を選ぶ。** 誰に、誰の名前を渡すか。それが預かり屋の労働。
5. **渡せない名前がある。** 記憶が重すぎる名前、誰も引き取らない名前。預かり屋の棚に残る。
6. **自分の名前を預かり屋に返す者もいる。** 生きたまま、名前を捨てる。返された名前は、棚の奥に置く。

## 主人公(役割だけ。名前は決めない)
- 預かり屋。名前を預かり、渡すのが仕事。
- **本質(変えない)**: 怖がり。言葉が少ない。名前を渡すとき、毎回手が震える。
- **過去(守れなかった)**: 預かり屋になる前、誰かの名前を預かりそこねた。その人の名前は、どこにもない。
- **今の悩み**: 棚に、自分が誰にも渡せない名前が一つある。誰の名前かは、視聴者にも明かさない(終盤まで)。
- **持ち物**: 名前を書く帳面と、空の札が一枚。空の札は、預かりそこねた名前の分。

## 相棒(翻訳役)
- 名前を返した者。生きているが、名前がない。預かり屋の隣にいる。
- 主人公の感情を、代わりに言う(「こわがってる」「うれしいって」)。自分の感情は言わない。
- 過去: なぜ名前を返したかは、全体で1回だけ見せる。

## 感情移入の仕掛け(この世界の中心)
| 仕掛け | 中身 |
|---|---|
| **視点を主人公に固定する** | 視聴者が知ることは、主人公が知ることと同じ。主人公が見ていない場面は描かない |
| **主人公と一緒に「選ぶ」** | 毎話、誰にどの名前を渡すかを、主人公が選ぶ。視聴者も同じ札を見て、同じ時間で迷う |
| **渡した後に、記憶が見える** | 名前を渡した瞬間、付いていた記憶が1カット見える。主人公も視聴者も、そこで初めて知る |
| **手の震えを、毎回描く** | 主人公の怖さを、体で見せる。言葉にしない |
| **選び間違える** | 主人公は、時々、間違った名前を渡す。渡された子が、重い記憶を抱える。取り消せない。視聴者も一緒に後悔する |
| **視聴者の指を、札に置かせる(ショートの場合)** | 冒頭に「ゆびで えらんで」。視聴者が札を選ぶ体にする。選んだ札の記憶が見える |

## 共感の仕掛け
| 仕掛け | 中身 |
|---|---|
| 労働 | 名前を預かり、渡す。毎日。帳面に記す。検定がある(「預かり三級」など)。合格しても、渡せる名前が少し増えるだけ |
| 言えない言葉 | 主人公は、渡す相手に「この名前は重い」と言えない。相棒が代わりに言う |
| 守れなかった過去 | 預かりそこねた名前。空の札 |
| 弱いまま | 主人公は、最後まで手が震える。震えたまま、渡す |
| 小さな幸せ | 渡した名前を、子どもが気に入る。それだけで、その日は終わる |

## 考察の仕掛け
| 仕掛け | 割れる解釈 |
|---|---|
| 空の札 | 誰の名前が入るはずだったか。主人公自身か、相棒か、「向こう」の誰かか |
| 棚の奥の、渡せない名前 | 誰の名前か。終盤に一度だけ、札の裏が見える。文字は読めない |
| 名前に付く「記憶が一つだけ」 | なぜ一つか。誰が選んでいるか。預かり屋か、名前そのものか |
| 人口が減った理由 | 町ごとに別の伝説がある。全部は語らない |
| 「向こう」 | 技術を独占する場所は、あるのか。名前を返した者は、そこへ行くという噂 |
| 相棒が名前を返した理由 | 1回だけ見せる。見せても、解釈は割れるようにする |
| 帳面の最初のページ | 主人公の字ではない |
| 画面の端の数 | 毎話「棚の名前: ◯枚」。増えたり減ったりする。減った理由を描かない回がある |

## 全員の過去と悩み(役割ごと)
| 役割 | 過去 | 今の悩み | 見せ方 |
|---|---|---|---|
| 預かり屋(主人公) | 預かりそこねた名前 | 渡せない名前が一つある | 空の札。手の震え |
| 相棒 | 名前を返した | 自分の感情を言えない | 全体で1回 |
| 名前をもらう子どもたち | 前の持ち主の記憶を一つ抱える | 自分の記憶か、他人の記憶か分からない | 記憶の1カット |
| 名前を返しに来る者 | 名前と一緒に、何かを捨てたい | 捨てても、記憶は残る | 返す時の持ち物 |
| 直し屋(機械を直す者) | 強くなる代わりに、名前を二つ持った | 二つの記憶が争う | 主人公を見る目 |
| 名前を奪う者(敵) | 誰かの名前を守ろうとして、奪う側になった | 奪った名前を、渡せない | 別れた後に、守ろうとした相手が1カット |
| 名前のない者たち | 持ち物に、前の名前の跡 | 描かない | 持ち物だけ |

## 主人公の「成長」(本質は変えない)
| 何が変わるか | 最初 | 最後 |
|---|---|---|
| 決断 | 重い名前は、棚に戻す | 重い名前を、震えながら渡す |
| 言う相手 | 相棒にしか言わない | 渡す相手に、一言だけ言う |
| 怖さの中身 | 間違えるのが怖い | 渡せないまま終わるのが怖い |
| 空の札 | 持っているだけ | 最終話で、空の札に何かを書く(何を書いたかは見せない) |

## 縦軸の問い
**「渡せない名前は、誰のものか。」**
- 最終話でも、一つの答えに決めない。
- 最終話は、第1話と同じ構図(棚の前、帳面、空の札)で始まり、渡す/渡さないの選択だけが違う。

## 1話の型(ショート15〜30秒 / 長編1〜2分、どちらにも使える)
| 順 | 中身 | 軸 |
|---|---|---|
| 1 | 「棚の名前: ◯枚」。預かり屋が棚の前に立つ。(ショート: 「ゆびで えらんで」) | 考察・感情移入 |
| 2 | 名前をもらいに来た子、または返しに来た者。主人公の手が震える。相棒が感情を言う | 感情移入・共感 |
| 3 | 主人公が札を選ぶ。視聴者も同じ札を見る。迷う時間を同じにする | 感情移入 |
| 4 | 渡す。付いていた記憶が1カット見える。説明なし | 感情移入・考察 |
| 5 | 帳面に記す。短い言葉(「わたした」「かえった」「まだ」) | 共感 |
| 6 | 小さな良いこと一つ。棚の数が変わる | 共感・考察 |
| 7 | 空の札が、画面の端に映って終わる | 考察 |

## 全体の型
- 全話数を最初に決め、完結させる。毎話は独立して見られる。
- 普段は「渡す日」の短い話。数話に一度、「返しに来る者」「奪う者」の長い話。
- 殺伐は、名前の奪い合いと、重い記憶を押し付けられる子どもで作る。やさしさは、渡した名前を子どもが気に入る瞬間で作る。配分は殺伐6、やさしさ4(私の目安。根拠はない)。

## 限界
- 創作案で、効果の証明はない。設計原則そのものが批評・編集者の見立てに基づく。
- 「名前を預かる」「死者の名前を継ぐ」という設定は、既存の作品と似ている可能性がある。確認はしていない。
- 殺伐の程度は、公開先と視聴者層で調整が要る。
