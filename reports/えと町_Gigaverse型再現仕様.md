# えと町 × playgigaverse型 再現仕様(2026-10-05)

根拠: `日本ショート競合チャンネル分析.md` のplaygigaverse詳細(直近43本、2026-04〜10)。数値はn=43の観察で、因果ではない。

## 再現する(構造・運用)
| 項目 | Gigaの実績 | えと町での適用 |
|---|---|---|
| 尺 | 8〜24秒、中央値13秒。16秒以上は中央値756万 | 主力は15〜24秒。30〜45秒版と1:1で比較 |
| 型の配分 | ストーリー(オチ)中央値1,862万 / 画面操作451万 / チャレンジ337万 | ストーリー5割 / 視聴者参加(スワイプ・長押し等)3割 / 問いかけ・チャレンジ2割 |
| オチ | 「待てばオチがある」。教訓ではなく驚き・感情 | 最後は絵のオチ。一行は別動画でA/B |
| タイトル | 短い一文+絵文字+行動の促し(例: 最後まで見て) | 日本語の短文+絵文字。「自主制作アニメ」は付ける |
| 好奇心の型 | 「最初のコメントを見ないで」系が3,326万など | 固定コメントに誘導する型を月1回まで |
| キャラ | 固定キャラ1体が主役、言語に依存しない | ルーチェ主役。冒頭は絵で見せ、テロップに頼らない |
| 頻度 | 週約1.7本(9月に急増→1本あたり減) | 週2本までを上限にし、増やさない |
| 節目 | 100万人到達を動画化 | 1,000人・1万人到達を動画化 |

## 再現しない(理由)
- Giga Noobのキャラデザイン、動画、場面構図、タイトルの流用: 著作権の侵害や模倣と見なされ、「再利用されたコンテンツ」としてYPPに影響する恐れ。
- 同じタイトルの再投稿: Gigaでも2,183万→721万と約1/3に落ちた。

## 最初の5本の例(えと町版)
1. **ドングリ半分**: ルーチェと小さなネズミがドングリを分ける。最後に割れた中から芽が出る(ポップコーン型)
2. **スワイプでコーヒーを冷ます**: スワイプでピョンのコーヒーがちょうどよい温度になる(参加型)
3. **13番目の席**: 輪の空席に誰が座るか。最後に見ている人の視点が映る(オチ型)
4. **和時計の針を止めるな**: 長押しで針を回す参加型
5. **まばたきチャレンジ**: ルーチェと目をそらさずに何秒耐えるか(チャレンジ型)

## 検証指標(最初の5本)
視聴を続けた率70%以上 / 平均視聴率80%以上 / 15〜20秒版が30〜45秒版を上回るか / ストーリー型が参加型より伸びるか
